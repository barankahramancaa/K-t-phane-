# 📚 Kütüphane Yönetimi

C# ile yazılmış bir konsol uygulaması. Kitap ekleme, listeleme, arama ve silme işlemlerini yapar.

## Özellikler
- Kitap ekleme (ad ve yazar)
- Tüm kitapları numaralı listeleme
- Kitap adına göre arama
- Numarasına göre kitap silme

## Kullanılan konular
- Class, constructor ve property (`get` / `set`)
- `List<Book>` ile nesne listesi
- `while` ile menü döngüsü, `if` / `else if`
- `for` döngüsü ile listeleme ve arama

## Nasıl çalıştırılır
1. Projeyi Visual Studio ile aç
2. `Ctrl + F5` ile çalıştır
3. Menüden 1-4 arası bir seçim yap, çıkmak için 0
